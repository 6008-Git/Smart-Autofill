# Smart Autofill 0.3.2

校招投递很多次，个人资料维护一次。点击输入框，选择已有资料，确认后填写当前字段。

## 本次发布

- 140 项资料定义、13 个分类、7 类可增删记录与英文键 JSON 导入导出。
- 按学校、公司、项目和时间摘要查找经历，支持中文/英文键搜索。
- Alt+Z 手动唤起，支持匹配 iframe 与开放 Shadow DOM 原生输入框。
- 规则推荐不准确时可手动选择；下拉框和提交操作始终由用户完成。
- 本地存储，无后端、远程模型调用或第三方运行依赖。
- 中英文 README、贡献指南、问题模板与 CI。

## 安装

下载 `smart-autofill-0.3.2.zip`，解压，在 Chrome/Edge 扩展管理页开启开发者模式，加载解压后的 `smart-autofill` 文件夹。打开扩展图标中的管理页，填写或导入自己的资料。

更新后重新加载扩展，并刷新已有招聘网页。无需重新导入原有资料。

## 验证与边界

28 项单元测试通过；独立虚构资料配置下，Chrome/Edge 各 46 项浏览器检查通过。CI 验证单元测试、公开文件与打包，不执行浏览器检查。

支持原生文本、电话、邮箱、数字输入框和 textarea。下拉框、日期组件、密码、不可编辑控件、contenteditable 和浏览器禁止注入的页面不在当前填写范围。没有整页自动填写或自动提交功能。

`SHA256SUMS.txt` 提供扩展 ZIP 校验值。完整说明见 README。
