# Smart Autofill 0.3.3

## 修复

- “某表单填……”和括号中的明确表单来源不再混入填写内容，导入和旧资料读取使用相同清理规则。
- 原说明移入管理页备注或数据来源；这些字段以及待补充项不再出现在填写菜单。
- 单值字段的矛盾来源需要人工确认，不自动合并为错误值；真实资格名称和多段文本保留。
- 高中经历可独立维护、搜索和填写，不覆盖大学经历的常用字段；不推断高中学位、学院或专业。

## 更新方法

下载并解压 `smart-autofill-0.3.3.zip`，在扩展管理页加载或重新加载 smart-autofill 文件夹，然后刷新已打开的网页。

旧资料中的明确来源标记会在读取时整理。保存或导出后可保留清理结果及原始说明。新增的个人经历应通过管理页维护或自己的 JSON 导入，公开扩展包不包含个人资料。

## 验证

35 项单元测试，Chrome/Edge 各 48 项独立虚构资料浏览器检查。新增检查覆盖说明清理、原文保留、元数据排除、高中经历与常用教育信息的独立性。下拉框仍由用户选择。
